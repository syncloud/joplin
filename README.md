# Joplin

[Joplin Server](https://github.com/laurent22/joplin/tree/dev/packages/server) packaged for [Syncloud](https://syncloud.org).

Synchronise notes between the Joplin desktop and mobile apps through your own device.

Sign-in uses Syncloud SSO. Members of the `syncloud` group are Joplin Server admins.

In the Joplin app choose Configuration → Synchronisation → Joplin Server (SAML), enter `https://joplin.<your domain>`, sign in through Syncloud in the browser and paste the code it shows.
